      On-device capabilities

      Core security features

      A local-first security design with clear capability boundaries. Detection coverage is limited and remains under validation.

      Multi-Engine

      Local SHA-256 checks and bounded DEX inspection through five Kotlin YARA-compatible rules. The bundled offline hash is currently EICAR-only; rule matches are advisory, not full YARA detection.

      Incident Response

      A five-second alarm-stream siren, security notification and user-confirmed uninstall flow. Android permissions, Do Not Disturb and OEM background rules can affect alert delivery.

      Privacy-First

      Core scans and history stay on-device. Optional user-approved threat contribution sends a SHA-256 indicator only; private quarantine is encrypted and user-controlled.

      Pro Tier

      ₹299 annual India list price, subject to the active Google Play offer. Active Pro entitlement excludes AdMob; access is cached locally in an encrypted device-bound entitlement.

      Under the hood

      Engineering Architecture

      The implementation separates local detection, signed intelligence, experimental ML and private persistence. Each layer has explicit limits.

      Security Layer Available Capability / Limitation
      On-device detection Local SHA-256 matching (the bundled offline definition is currently the harmless EICAR test marker only) and limited DEX/YARA-compatible signatures. Limitation: no kernel privilege; Android sandbox and package-visibility restrictions apply.
      Signed intelligence Optional cryptographically verified SHA-256 hash-definition updates. Limitation: online retrieval is optional, network-dependent and requires a configured trust root.
      ML research SHA-256-pinned, 215-feature TFLite trained research candidate. Limitation: validated=false; no production ML classifications.
      Privacy & persistence Local scan history in Room/DataStore and Keystore-backed sensitive records. Limitation: no developer-operated cloud account or developer-controlled backup.

      The Android app has no kernel privilege. Static inspection does not execute APK code and cannot observe every runtime, packed, native or dynamically loaded behaviour.
